# 段表数据（segment_data）

号码生成各国家的真实数据段表，由批量测试实测收敛后生成。

## 文件格式
每行：`段\t频次`（tab 分隔），按频次降序排列。
段格式因国家而异（美国=区号3+交换码3；巴西=区,X后Dom区2+号段2已去55；智利=网络码前缀含9）。

## 各国段表及exe档位
| 文件 | 全集段数 | 最优档段数(默认) | 最大量档(备选) |
|------|---------|-----------------|---------------|
| us_top1000.txt | 1000 | 500 | 1000 |
| br_top400.txt | 400 | 100 | 400 |
| cl_top500.txt | 500 | 300 | 500 |

## 说明
- 档位由 exe 的"配置"下拉切换：最优(默认,量大+命中平衡) vs 最大量(量大优先)。
- 段表内嵌在 NumMagic.cs 的数组（全集 + PickWeighted 限幅钳制档位）。
- 数据源路径 /tmp（WSL 临时），备份到此以便重算。

## 历史实测命中（5万批）
| 国家 | 最优档 | 最大量档 |
|------|--------|---------|
| 美国 | 500段 58.3% | 1000段 ~57% |
| 巴西 | 100段 37.5% | 400段 37.2% |
| 智利 | 300段 36.4% | 500段 33.8% |

## 说明
- 段格式因国家而异：美国=区号3+交换码3；巴西=去国家码后4位(区2+号段2)；智利=网络码前缀(4位含9)。
